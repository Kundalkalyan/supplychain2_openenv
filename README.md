# SupplyChain2 Open Environment

A simulation and optimization environment for supply chain management, designed to model inventory, demand, transportation, and logistics operations. This project provides a flexible framework for experimenting with supply chain strategies, resource allocation, and decision-making algorithms.

## 📖 Overview

Supply chain systems involve complex interactions between suppliers, warehouses, distribution centers, and customers. This project aims to provide an open environment for:

- Supply chain simulation
- Inventory management analysis
- Demand forecasting experiments
- Logistics optimization
- Decision-support system development
- Reinforcement Learning and Operations Research applications

The environment can be used by students, researchers, and developers to study and improve supply chain performance.

---

## 🚀 Features

- Supply chain network simulation
- Inventory tracking and management
- Demand generation and forecasting
- Transportation and distribution modeling
- Cost analysis and performance metrics
- Extensible architecture for custom algorithms
- Open environment for experimentation and research

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Kundalkalyan/supplychain2_openenv.git
cd supplychain2_openenv
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Usage

Run the main application:

```bash
python main.py
```

Or execute a simulation:

```bash
python simulation.py
```

Modify configuration parameters to experiment with different supply chain scenarios.
